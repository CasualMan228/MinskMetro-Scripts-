# MinskMetro-Scripts-

Исходный код моего Unity3D-прототипа, посвященного Минскому метрополитену

## 🚧 Minsk Metro Prototype 🚧

Встречайте станцию метро **«Аэродромная»** вместе с новым поездом Минского метрополитена **«Минск-2024»**

### Реализованные функции

* Меню с выбором уровня графики
* Вид от первого лица
* Передвижение игрока
* Меню настроек: FOV, чувствительность мыши и громкость
* Воссозданная станция метро «Аэродромная»
* Поезд «Минск-2024»

### Версия

**v. 0.0.1 Alpha (Unpatched)**

**Платформа:** Windows

### О репозитории

Репозиторий содержит C#-скрипты проекта Minsk Metro Prototype. Сцены Unity, модели, текстуры и остальные ассеты (игровые ресурсы) не включены
